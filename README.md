# Monthly Expense Classifier

The **Monthly Expense Classifier** is Python project that analyzes a user's monthly income and expenses. It calculates the remaining income, determines the percentage of income spent, and classifies the user's expense level.

## Features

- Accepts monthly income and expense inputs
- Calculates remaining income
- Calculates the expense rate
- Uses Boolean logic to identify high expenses
- Classifies expenses as **Low, Moderate, or High**

## Technologies

- Python 3
- Jupyter Notebook

## How to Run

Run the Python code and enter your monthly income and expenses when prompted.

The program will display the remaining income, expense rate, and expense classification.

## Learning Objectives

This project includes:

- User input
- Variables
- Arithmetic operations
- Boolean expressions
- `if`, `elif`, and `else` statements
- Basic data analysis
